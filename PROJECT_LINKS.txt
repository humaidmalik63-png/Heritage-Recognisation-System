PLATFORM ARCHITECTURE & SPECIFICATIONS
================================================================================
- Vision-Language Model: OpenAI CLIP ViT-B/32 (512-D Dense Feature Extraction)
- Vector Index: FAISS Flat Inner-Product Index (577 normalized embeddings across 100 sites)
- Tier-2 Adjudication VLM: Google Gemini 3.1 Flash-Lite (Multimodal Verification)
- Backend Framework: FastAPI on Python 3.12 with Uvicorn ASGI server
- Frontend Framework: React 19 + Vite + Tailwind CSS + Framer Motion
- Hosting Infrastructure: Vercel (Frontend Global Edge CDN) + Railway (Backend Container)
